# CodeAlpha - Quotes Web Scraping

## Project Overview

This project is developed as part of the CodeAlpha Data Analytics Internship.

The objective of this project is to extract quotes, author names, and tags from a public website using Python and BeautifulSoup, and create a custom dataset for data analysis.

## Website Used

https://quotes.toscrape.com/

## Tools and Libraries

* Python
* Requests
* BeautifulSoup
* Pandas

## Features

* Extracts quote text from the website
* Extracts author names
* Extracts quote tags
* Stores data in a CSV file
* Creates a custom dataset for analysis

## Dataset Fields

* Quote
* Author
* Tags

## How to Run

1. Install required libraries:

pip install requests beautifulsoup4 pandas

2. Run the script:

python quotes_scraper.py

3. The dataset will be saved as:

quotes_dataset.csv
